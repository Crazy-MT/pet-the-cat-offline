# Pet the Cat · 摸猫模拟器

感谢原作者 [@zubububu](https://x.com/zubububu) 创作了这个摸猫网页！

本仓库保存了[原版网页](https://pet-the-cat.pages.dev/)的 HTML 副本，方便离线体验。下载 `index.html` 后，双击即可在浏览器中打开。
